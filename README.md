# 💰 Budget Planner with Charts

A responsive monthly budget planner built using HTML, CSS, JavaScript, Chart.js and LocalStorage.

## 🚀 Features

- Set budget for different categories
- Add monthly expenses
- Track spending category-wise
- Calculate total budget
- Calculate total spending
- Calculate remaining budget
- Budget vs Actual Spending chart
- Over-budget warning
- Delete individual expenses
- Reset all data
- Data saved using LocalStorage
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No backend or installation is required.

## 📊 How It Works

Users first set a budget for categories such as:

- Food
- Travel
- Shopping
- Bills
- Education
- Entertainment
- Health
- Other

Then users can add expenses.

The application automatically calculates spending using JavaScript's `reduce()` method and compares the actual spending with the category budget.

## 💾 LocalStorage

Budget and expense information is stored in the browser using LocalStorage.

Therefore, refreshing the page does not remove the saved data.

## 📈 Chart

Chart.js is used to create a bar chart comparing:

Budget vs Actual Spending
